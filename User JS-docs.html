用户脚本安装教程

通过浏览器插件安装，每次访问指定网页时会自动执行。

安装浏览器插件
推荐暴力猴 需开启同步 page 模式
前置步骤

推荐选择暴力猴，因为篡改猴加载速度会更慢，可能会带来一些问题。暴力猴要开启同步 page 模式。

📥 下载地址
篡改猴 (Chrome) 暴力猴 (Chrome) 篡改猴 (Firefox) 暴力猴 (Firefox) 篡改猴 (Edge) 暴力猴 (Edge)
⚠️ 重要：允许用户脚本
需要给篡改猴或暴力猴开启「允许用户脚本」选项。
安装用户脚本
三种方式

在线安装、通过脚本链接安装、离线安装，任选其一。

① 在线安装
  1. 访问 用户脚本列表
  2. 点击任意脚本，会询问是否安装
② 通过脚本链接安装
  1. 打开篡改猴或暴力猴的管理面板
  2. 篡改猴点「通过 url 安装」，暴力猴点「通过地址安装」
  3. 点击安装
③ 离线安装
  1. 打开篡改猴或暴力猴的管理面板
  2. 把下载好的 js 文件拖进去，会询问是否安装
常见问题
FAQ
脚本没有生效怎么办？
  • 确认脚本已启用，并且匹配的网址正确
  • 检查浏览器插件是否有权限访问该网站
  • 尝试刷新页面，或重启浏览器
  • 查看浏览器控制台是否有报错信息
🔄 如何更新脚本？
  • 重新访问脚本链接并安装即可覆盖旧版本
  • 部分插件支持自动更新，可在设置中开启
🚫 安装时提示“无法安装脚本”？
  • 确保已开启篡改猴/暴力猴的“允许用户脚本”选项
  • 检查脚本文件是否完整，尝试重新下载
  • 如果是远程链接，确认链接可正常访问
